# PortoIQ 📦

**Hinweis:** Dies ist eine private Web-Applikation für den persönlichen Gebrauch. 

PortoIQ ist ein einfacher Versandrechner für Pakete innerhalb Deutschlands (DHL, Hermes, DPD, GLS).

## Features

*   **Tarifrechner:** Vergleich basierend auf Maßen & Gewicht.
*   **Local First:** Daten und API-Keys werden nur im Browser gespeichert.
*   **KI-Update:** Optionale Preisaktualisierung via Google Gemini API (BYOK).
